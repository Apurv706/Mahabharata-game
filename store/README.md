# Store assets

Steam store and library images, ready to upload. Built by artist B from the 1672×941 key art and the font-based logos (see `ARTIST_README.txt`).

- `steam/` — header and library header (920×430), small (462×174), main (1232×706), vertical (748×896), library capsule (600×900), page background (1438×810), library logo (1280×312), icons (256 and 184).
- `master/` — the key art at native size, both logos (PNG and SVG, light and dark), and the Cormorant Garamond licence (SIL OFL 1.1).
